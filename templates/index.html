HTTPS Email API Integration Details

The attendance system automatically dispatches parent absence emails via HTTPS REST API (Port 443) when Admin finalizes attendance.

  • Render Free Compatible — Bypasses Render's outbound SMTP port blocking.
  • Free Tier Supported — Resend (3,000/mo free) or Brevo (300/day free).
  • Timing — Triggered ONLY after Admin clicks FINALIZE ATTENDANCE.
  • Duplicate Protection — Prevents sending multiple emails per session/student.
  • Masked Logs & Keys — Parent emails and API keys masked securely in database logs and UI.
